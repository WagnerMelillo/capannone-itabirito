# Preferências de interface do projeto

- Priorizar uma apresentação bonita, estilosa e com design profissional, sem sacrificar clareza ou segurança.
- Para dados estruturados, preferir edição em formato de planilha ou grade, com colunas claras e ações simples.
- Manter as telas responsivas, intuitivas para pessoas não técnicas e preparadas para impressão quando aplicável.
- Usar a identidade visual da Capannone com equilíbrio: verde, tons quentes, boa tipografia e espaçamento confortável.
